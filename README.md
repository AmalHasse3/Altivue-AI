# ✈️ Altivue AI

### Enterprise Aviation Innovation Intelligence Platform

Altivue AI is a cloud-native enterprise intelligence platform designed to help organizations analyze emerging technologies, evaluate startup ecosystems, monitor innovation trends, and generate AI-powered strategic insights for decision-making.

Built with modern full-stack engineering, cloud infrastructure, cybersecurity practices, AI integrations, and scalable deployment workflows, Altivue AI combines software engineering, analytics, product strategy, and enterprise architecture into one production-grade platform.

# ⚙️ Local Development Setup

## 1. Clone Repository

```bash
git clone https://github.com/AmalHasse3/altivue-ai.git
cd altivue-ai
```

---

## 2. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:

```bash
http://localhost:3000
```

---

## 3. Backend Setup

```bash
cd backend
python -m venv venv
```

### Activate Environment

Windows:

```bash
venv\Scripts\activate
```

Mac/Linux:

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Backend

```bash
uvicorn app.main:app --reload
```

Backend runs on:

```bash
http://localhost:8000
```

# 🔑 Environment Variables

Create a `.env` file inside the backend and frontend directories.

Example:

```env
OPENAI_API_KEY=
GEMINI_API_KEY=
SUPABASE_URL=
SUPABASE_KEY=
DATABASE_URL=
JWT_SECRET=
AWS_ACCESS_KEY_ID=
AWS_SECRET_ACCESS_KEY=
```
